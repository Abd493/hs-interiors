# H-S Interiors — Luxury Interior Design & Architecture

A pixel-perfect, high-performance web platform for **H-S Interiors** (Gujranwala, Pakistan), featuring bespoke luxury interior architecture showcases, 4K UHD imagery, interactive Before/After renovation comparison slider, masonry portfolio with lightbox, and direct WhatsApp consultation booking.

Live URL: [https://hsinteriors.vercel.app](https://hsinteriors.vercel.app)

---

## ✨ Features

- **Luxury Theme:** Bespoke obsidian `#12100F` and warm champagne gold `#C59B27` palette.
- **Hero Slider:** Cinematic Ken Burns transitions with 100% legible frosted contrast overlays.
- **Services Showcase:** Modern horizontal layout with custom icon emblems and concise descriptions.
- **Before & After Slider:** Exact 1:1 camera angle renovation comparison between bare concrete shell and luxury finished room.
- **Portfolio Gallery:** Dynamic multi-category filterable masonry gallery with high-res lightbox viewer.
- **Client Testimonials:** Seamless slider highlighting verified client reviews.
- **Consultation & Contact:** Direct instant WhatsApp integration for bookings.
- **4K UHD Assets:** Crystal-clear high-definition imagery optimized with Lanczos resampling and sharpening.
- **Brand Identity:** Custom **HS** luxury gold monogram emblem, favicons (`.svg`, `.ico`, `.png`), and apple touch icons.

## 🛠️ Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite 5
- **Styling:** Tailwind CSS 3
- **Icons:** Lucide React
- **Hosting:** Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Abd493/hs-interiors.git

# Navigate to project folder
cd hs-interiors

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
```
